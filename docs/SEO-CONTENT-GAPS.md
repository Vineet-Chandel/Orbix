# Editorial gaps requiring owner input

The implementation uses existing source content and confirmed public publication fields. It does not invent product promises, founders, testimonials, dates or social accounts.

| Page/topic | Required input | Current handling |
|---|---|---|
| /customers | Customer permission, real quotations, named evidence and supported outcome measurements | Public route preserved; noindex; excluded from sitemap/schema claims |
| /pricing | Approved plan availability/prices and verification of enterprise/SLA/telemetry claims in the existing template | Public route preserved; noindex; no Product offers or price schema |
| /platform and /platforms | Reconcile the advertised platform list with the actual adapter registry; some showcase entries describe companion products | Metadata is neutral; no new claims or platform counts introduced |
| Organization/about | Public legal operator, contact route, approved official social profiles, founders if appropriate | Orbix brand + website only; no invented address, founders or sameAs |
| Documentation | Verify month-only update labels and stated capabilities against release history; provide genuine publication timestamps and bylines | No manufactured lastmod, author or datePublished |
| Physical events | Actual venue street/locality/country, accessible registration requirements and ticket information if applicable | Event name/date/organizer and visible venue are used; no fabricated address/offers |
| Personal profiles/certificates | A separately approved search-indexing consent policy, if this is ever desired | Explicit noindex; no Person entities or personal-record sitemaps |
| Important instructional video/audio | Human-reviewed captions/transcripts and accessible source media | Existing controls preserved; transcripts are not fabricated |
| GEO/AEO evaluation | Owner-approved queries, markets, brand mentions and a dated evidence log | No claims that schema, robots or this implementation guarantees citations or rankings |

Homepage/about now explain what Orbix provides, who uses it, how users connect accounts, how to review visibility and where to find public events. Answers refer to real application features and link to public documentation. FAQPage rich-result markup is intentionally omitted: Orbix is not an authoritative government/health site, and generic FAQ markup is not a ranking requirement.
